# C4-LOCAL-001 — certified local fast-forward integration

**Objective/base.** From clean, independently source-reviewed `8f271de796e643a3a0b9b47b80fc1de3e3646d9d`, implement one controller-owned path that advances a dedicated local integration ref to an already reviewed, C3-certified slice commit and durably marks that slice verified. This first node handles **linear fast-forward commits only**; conflicting or merge-required candidates become blocked for a later resolution packet. No GitHub publication or operational activation is claimed. One Luna owns this packet in one isolated worktree; retry budget two materially different bounded repairs.

**Owned files.** Add `packages/integration/src/local.ts` for bounded Git-plumbing inspection and compare-and-swap (CAS); extend `packages/contracts/src/mission.ts`, `packages/contracts/src/sql-mission-store.ts`, `packages/governor/src/governor.ts`, and `apps/control-plane/src/server.ts` only for a typed controller integration request and authenticated owner route. Add `db/migrations/006_integration.sql` for one durable intent keyed by mission/slice/lease epoch, expected ref SHA, candidate/tree SHA, certificate IDs/digests, review digest, state and observed ref SHA. Update `packages/contracts/src/memory-mission-store.ts` only to keep production parity closed or support deterministic contract tests. Add focused tests under `tests/` and a packet completion record. Do not edit C3 certificate issuance, runner limits, learning promotion, scheduling, PR #2 broker, GitHub adapter, main, or existing evidence.

**Callable boundary.** Introduce `Governor.integrateVerifiedSlice(request, trustedChecks, localIntegrator)` and one owner-session `POST /api/missions/:id/slices/:sliceId/integrate` route; no worker route or lease capability can call it. Request names exact expected integration-ref SHA, candidate SHA, lease epoch, required check IDs, and controller-owned independent review artifact reference/digest. Reject arbitrary ref paths and unapproved repository maps. The integration ref is **distinct** from C3's approved candidate ref: `getCertificate()` observes the latter and must return current `local-exact-commit` certificates for this slice/candidate. A worker result, review string, receipt alone, or source-commit certificate for a different integrated SHA is insufficient. Verify the actual retained independent PASS artifact binds candidate/tree, reviewer identity distinct from builder, and applicable scope; missing review closes the path.

**Sequence.** Under the existing Governor lock, require approved plan, `awaiting_verification`, unchanged lease epoch/candidate/policy/plan, all mandated final-purpose PASS certificates with exact candidate, local head, policy/image/request/receipt/artifact bindings, and no unresolved UNKNOWN. Require dependencies verified and approved scopes. The local integrator reads a complete bare object store using the verifier's safe Git conventions; rejects symlink/gitlink, unsafe/case-colliding paths, hooks/filters/alternates/shallow repositories, and changed paths outside the slice scopes. Require candidate to descend from expected integration head, with no unreviewed intervening commit. Record an idempotent intent **before** Git CAS. CAS the dedicated ref with `git update-ref <ref> <candidate> <expected>`; never checkout or execute candidate code. Re-read the ref, then reacquire the lock and recheck all fences before `SqlMissionStore.integrate()` atomically records the integrated SHA, evidence and single event, marks `verified`, refreshes mission status, and releases only dependency-bound ready children. SQL/Git are not one transaction: restart reconciles pending intent from exact observed ref and original evidence; an unexpected ref or ambiguous write is UNKNOWN and never blindly retried. Duplicate exact requests return the same result; conflicting requests fail.

**Acceptance.** Real disposable bare Git plus PostgreSQL-compatible tests: one certified fast-forward and dependent child release; duplicate/restart after CAS; moved ref; missing/stale/wrong-SHA or partial certificate; absent/rejected/self review; path escape, scope overlap, symlink, unrelated/intervening commit, and merge conflict; injected interruption before/after CAS with no false verified state. Preserve default-closed production wiring until the integrated candidate itself has real C3 cloud acceptance and real PostgreSQL/restart proof. Run focused tests, then exact-candidate clean build, typecheck, full tests, validation, syntax/diff gates and independent review. Handoff records SHA, intent/ref/SQL evidence, commands, exits, UNKNOWNs, and no publication claim.
