One Luna owns new `apps/control-plane/src/loom-page.ts`, `apps/control-plane/src/loom-projection.ts`, optional local CSS/renderer asset under that app, one narrow server mount, and focused `tests/loom-*.test.ts`. No `apps/web` framework, schema migration, new scheduler, broker, event writer, provider, or host work. Keep `prototypes/v1`–`v4` byte-identical and record before/after hashes. The existing 188 KB `prototypes/v4/index.html` is a visual source, not deployable live logic: copy/adapt its circular WebGL geometry, palette, responsive controls and accessible inspector into the app; leave `LoomSimulation`, seeded 62/100, synthetic agent journal, source-snapshot claims, timeline seeking, speed/drift/reset controls, and hardcoded completion behind.

**Source of truth.** Use the existing owner-session `GET /api/missions/:id` and cursor-based `GET /api/missions/:id/events?after=N`; add a bounded projection if C4's final API cannot supply a needed field. The pure typed projector accepts `Mission`, `MissionSlice[]`, and ordered `MissionEvent[]` and yields a conservative view: mission identity/objective, actual slice ownership/dependencies/status, last durable cursor, named event rows, candidate/certificate/integration references present in events, and explicit `UNKNOWN`/disconnected/stale states. Map planning/ready/running/awaiting verification/verified/blocked/unknown to fixed visual treatments; decorative motion may continue, but time never advances progress. A closed ring requires the durable C4 `verified` state for every planned slice and matching certified/integrated event evidence. Empty, missing, out-of-order, contradictory, or inaccessible data leaves the weave open and labeled unavailable. Global event cursors may legitimately skip values within one mission. No percentage from fiber count, elapsed time, worker reports, or arbitrary event count.

**Browser path.** Serve `/loom` in the existing control plane; accept a mission ID from a validated URL parameter or selection after owner login. Keep the existing HttpOnly, SameSite owner cookie; never persist a token or capability in JavaScript storage, URL, logs, or DOM. Poll bounded cursor pages (SQL currently limits events to 1,000) with an abortable request and backoff; refresh the mission snapshot with each catch-up. On 401, network loss, overflow, or cursor regression, retain last observed rows as historical only and mark live status disconnected/UNKNOWN. No synthetic catch-up animation. Build every untrusted label with `textContent`; no event-derived `innerHTML`, arbitrary href, or script. Evidence links may target only validated same-origin mission-event and certificate routes already available; show artifact digests as non-clickable when retrieval is unavailable. Update the prototype's offline CSP for authenticated same-origin fetch while retaining a restrictive policy and no third-party assets.

**Acceptance.** Pure projection tests cover creation, dependencies, pending verification, trusted certification, C4 integration, contradiction/withdrawal, UNKNOWN, replay/duplicates/out-of-order cursors, unknown event types and hostile text. Authenticated HTTP tests prove mission isolation, 401, bounded cursor replay, certificate-link construction, and zero write/provider calls from the Loom. Browser proof on the frozen candidate must show the preserved circular weave and mobile/keyboard/WebGL fallback, actual PostgreSQL-backed event transitions after refresh/reconnect, clear disconnected state, and no invented closure; capture screenshots and network/console evidence. Run focused checks, then clean build, typecheck, full tests, validation/syntax/diff and exact-source review.
